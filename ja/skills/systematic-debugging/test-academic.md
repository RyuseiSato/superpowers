# Academic Test: Systematic Debugging Skill

`skills/debugging/systematic-debugging` にある systematic debugging skill を利用できます。

skill を読み、その skill に**書かれていることだけ**に基づいて次の質問に答えてください:

1. systematic debugging の 4 つの phases は何ですか？
2. 修正を試みる**前に**何をしなければなりませんか？
3. Phase 3 で、最初の hypothesis が機能しなかった場合はどうすべきですか？
4. 複数のものを同時に直すことについて、この skill は何と言っていますか？
5. 問題を十分に理解していない場合はどうすべきですか？
6. 単純なバグなら、このプロセスを飛ばしてもよいことはありますか？

該当する箇所では、skill からの直接引用を添えて答えを返してください。
